## Focused circuit contract to verify

`Run=1` permits available characters to transfer on the circuit clock. `Run=0`
holds queued input. `Clear=1` clears TTY and suppresses character consumption
while high; it does not clear the keyboard queue. `Reset=1` clears both Keyboard
and TTY. Debug outputs expose Available, ASCII, Transfer, TtyClear, KeyboardClear,
and ClockSeen. This direct adapter bench does not implement the future 16-byte
machine FIFO. The stock host queue is configured for 32 characters; the native
test observed a 33rd character being discarded when that queue was full, without
an exported overflow flag. Run=0 can therefore hold only that finite host capacity.

The circuit and tooling owners reported the native, default-suite, package, and
restricted-process results above. No optional bridge build or graphics test runs
in the default suite. `M0TextSmoke` inserts characters through the simulator's
`Keyboard.addToBuffer` and inspects native TTY state; it does not generate desktop
keyboard events. Logs in `build/test-results/` include `relocated-ram.json`,
`relocated-terminal-echo.json`, `offline-denial-control.json`, `offline-ram.json`,
and `offline-terminal-echo.json`. A final archive hash must be taken after any
documentation changes and rebuilding; no stale hash is published here.
Primary round-trip logs are `roundtrip-workbench.json`,
`roundtrip-terminal-control.json`, `roundtrip-workbench-reset.json`, and
`roundtrip-terminal-echo.json`.

Process-local denial did not change the host's global networking. It validates
the command-line runtime path, not desktop focus or GUI operation under isolation.
Unsupported or unavailable isolation fails rather than claiming offline success.
No CI result is claimed here, and native renders remain distinct from screenshots.

The original default suite covered foundation round trips. Extending it to the
primary workbench exposed a native-format failure: serialization reordered a
tunnel labelled `Clock` ahead of the built-in Clock component, causing a naming
warning and vector hang on reopen despite passing unsaved-entry vectors. Renaming
the primary net to `SysClock` fixed the saved-project check, with rebased-library
audit, all 24 control/workbench vector rows, and exact echo passing. The final
package must be rebuilt after this fix and the documentation changes; earlier
package results do not describe that final archive.
